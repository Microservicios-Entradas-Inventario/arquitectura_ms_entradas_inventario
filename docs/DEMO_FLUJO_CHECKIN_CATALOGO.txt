================================================================================
DEMOSTRACIÓN DE FLUJO BACKEND: ENTRADAS <-> CATÁLOGO Y ENTRADAS <-> CHECK-IN
================================================================================
Entorno: API Gateway (http://localhost:8080) sobre red Docker plataforma-eventos-net
Servicios: entradas-service (:3003), ms-catalogo-eventos (:4000),
           checkin-service (:3005), auth-service (:10000)
