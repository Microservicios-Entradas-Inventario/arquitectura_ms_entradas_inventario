# GUÍA DE USO: PANEL VISUAL Y CONEXIÓN DE BASE DE DATOS

## 1. Levantar la Infraestructura
Para iniciar la base de datos MongoDB y el panel visual interactivo (Mongo Express), abre una terminal en la raíz del proyecto y ejecuta:

docker compose up -d

## 2. Acceder al Panel Visual (Mongo Express)
- Abre tu navegador web y dirígete a: http://localhost:8081
- No requiere autenticación (acceso directo).
- Una vez dentro, haz clic en la base de datos `ticketu_entradas_db`.
- Podrás visualizar, editar, crear o eliminar documentos visualmente desde las colecciones: `inventario_evento`, `reserva_entrada` y `entrada`.

## 3. Conexión desde el Back End (Node.js, Python, Java, etc.)
Para conectar los microservicios a esta base de datos local de manera directa, debes utilizar la siguiente URL de conexión:

mongodb://localhost:27017/ticketu_entradas_db
